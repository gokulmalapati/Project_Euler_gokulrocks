 Project Euler - 10001st Prime

In the code , we used a function is_prime which checks if a certain number is a prime or not.
We use a while to keep track of the no. of prime numbers and we go on increasing the value of n and the while loop stops at 10001st prime.
At that point the value of n would already be updated so we print n-1 to get the 10001st prime number.
